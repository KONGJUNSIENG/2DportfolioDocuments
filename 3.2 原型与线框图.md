## 二、Hero 区块详细规格（最核心）

### 2.1 布局参数

| 属性             | 值                                         |
| ---------------- | ------------------------------------------ |
| 高度             | `100vh`（100% 视口高度）                   |
| 布局方式         | Flexbox，`flex-direction: row`             |
| 左右比例         | 左（立绘）`60%` / 右（文字）`40%`         |
| 垂直对齐         | 右列 `justify-content: center`             |
| 内边距           | 左列 `0`（立绘贴左边缘），右列 `space-16` 右侧间距 |

### 2.2 左列：立绘区域

| 属性             | 值                                              |
| ---------------- | ----------------------------------------------- |
| 图片             | 透明背景 PNG，角色立绘                           |
| 高度             | `70vh`（留出顶部/底部呼吸空间）                  |
| 定位             | `object-fit: contain` + `object-position: bottom` |
| 最大宽度         | 100%（自适应列宽）                               |
| 叠加动效         | 轻微浮动 CSS 动画（`translateY(-3px → 3px)` 4s 循环） |
| 背景光晕         | 角色背后淡粉色渐变光晕脉冲（`@keyframes pulse`） |

### 2.3 右列：文字内容

```
┌─────────────────────────────────┐
│                                 │
│   やればできる！                 │ ← Slogan, font-family (ja), text-2xl (24px)
│                                 │   color-text-secondary, letter-spacing 0.05em
│   KONG JUN SIENG               │ ← text-4xl (36px), color-text-primary, font-weight 700
│                                 │
│   Software Developer /          │ ← text-lg (18px), color-text-secondary
│   全栈探索者                     │
│                                 │
│   ┌──────────────────┐          │
│   │ 查看作品          │          │ ← Primary 按钮
│   └──────────────────┘          │   bg-color-primary, text-white
│                                 │   padding: space-2 space-4, rounded-md
│   (CTRL + 滚动到底部内容)         │ ← 小字引导提示, text-sm, color-text-secondary
│                                 │
└─────────────────────────────────┘
```

各元素间距（从上到下）：
- `space-4`（Slogan → Name）
- `space-2`（Name → Title）
- `space-8`（Title → CTA 按钮）
- `space-6`（CTA 按钮 → 滚动引导）

### 2.4 背景

| 属性     | 值                              |
| -------- | ------------------------------- |
| 背景色   | `--color-background`            |
| 装饰元素 | 右侧大圆形渐变光晕（纯 CSS）     |
| 光晕大小  | 直径约 40vh，右侧偏上，半透明粉色渐变 |

### 2.5 Tablet 响应式（768px–1023px）

```
┌──────────────────────────────────────────────┐
│                                              │
│  ┌────────────┐  ┌────────────────────────┐  │
│  │            │  │ やればできる！           │  │
│  │  立绘      │  │ KONG JUN SIENG          │  │
│  │  缩小     │  │ Software Developer /    │  │
│  │  50%宽    │  │ 全栈探索者               │  │
│  │            │  │ [查看作品]              │  │
│  └────────────┘  └────────────────────────┘  │
│       ← 45% →       ← 55% →                 │
└──────────────────────────────────────────────┘
```

- Hero 高度：`min-h-screen`（不超过屏幕）
- 立绘宽度缩至 45%，高度 `50vh`
- 文字适当缩小：Name `text-3xl`，Slogan `text-xl`
- 背景光晕适当减弱

### 2.6 Mobile 响应式（<768px）

```
┌─────────────────────────┐
│     [导航栏 汉堡菜单]     │
│                         │
│  ┌─────────────────┐    │
│  │                 │    │
│  │   立绘截取上半身   │    │ ← 宽 70%，居中
│  │   50vh           │    │
│  │                 │    │
│  └─────────────────┘    │
│                         │
│  やればできる！          │
│                         │
│  KONG JUN SIENG         │
│                         │
│  Software Developer /   │
│  全栈探索者              │
│                         │
│  ┌──────────────┐       │
│  │  查看作品     │       │ ← 全宽按钮
│  └──────────────┘       │
│                         │
├─────────────────────────┤
│       ↓ 内容区块          │
└─────────────────────────┘
```

- **布局变列**：`flex-direction: column`，立绘在上文字在下
- 立绘：宽度 `70%` 居中，高度 `50vh`，`object-position: top`（截取上半身避免缩小后看不清）
- 文字：居中对齐，文本缩小一级
- 按钮：`w-full`
- 背景光晕：移动端消除，避免感知性能开销

### 8.1 Desktop 导航栏

```
┌──────────────────────────────────────────────────────────┐
│ [Logo]       案例    作品    关于    联系    中 / 日 / EN │
```
