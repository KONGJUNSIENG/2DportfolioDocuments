### 1.A.2 布局参数

| 属性 | 值 |
|------|-----|
| Navbar | 隐藏（`LayoutShell` 通过 `pathname === "/intro"` 判断隐藏 Nav/Footer） |
| Footer | 隐藏 |
| 背景色 | Phase 1 渐变背景；Phase 3 渐变 `from-primary-soft via-background to-background` |
| 角色立绘 | 全屏 `h-[100vh]`（桌面 `md:h-[136vh]`），`left-1/2 -translate-x-1/2`，图片 key 变化时重挂载淡入 |
| 对话框区 | 底部 `h-[30vh]`，渐变遮罩顶层，角色名 + 台词正文（无打字机效果） |
| 选项分支 | choices 数组，条件渲染 `bg-black/50` 全屏遮罩，选项加 ▶ 箭头，stagger 0.1s 入场 |
| Mouse Repell | 可选（`repel: true` 场景），鼠标200px内选项区反向偏移，`requestAnimationFrame` 驱动 |
| autoAdvance | 可选（`autoAdvanceMs`），自动选择第一个选项，useRef 锁 2s 防重复 |
| Skip 按钮 | 右下角，VNS 全程可见（无需延迟），点击直接触发 `onFinish` |
| 组件编排 | `IntroShell`（四阶段状态机）+ `IntroAnimation`（开场动画）+ `VNScenario`（VN 引擎） |

## 二、Hero 区块详细规格（最核心）

### 2.1 布局参数

| 属性             | 值                                         |
| ---------------- | ------------------------------------------ |
| 高度             | Desktop: `min-h-screen md:h-[90vh]`；Mobile: `min-h-[100dvh]`（自适应高度） |
| 布局方式         | Flexbox，`md:flex md:flex-row`（移动端列布局） |
| 左右比例         | 左（立绘）`md:w-[45%]` / 右（文字）`md:w-[55%]` |
| 垂直对齐         | 右列 `md:flex md:flex-col md:justify-center` |
| 内边距           | 左列 `0`（立绘贴左边缘），右列 `md:pr-16 md:pb-16` |
| 视差效果         | `useScroll()` + `useTransform`：scroll 0→0.3 时 y 偏移 -60px（桌面），光晕 opacity 0.6→0 |

### 2.2 左列：立绘区域

| 属性             | 值                                              |
| ---------------- | ----------------------------------------------- |
| 图片             | 透明背景 PNG，角色立绘（`/images/hero-character.png`） |
| 容器高度         | `h-full w-full`，`md:scale-[1.4] md:origin-top-left`（放大撑满） |
| 定位             | `object-fit: cover` + `object-position: center 45%`（截取上半身构图） |
| 图片 fill        | 使用 `<Image fill>` + `unoptimized`             |
| 叠加动效         | `character-float` CSS class: `translateY(0 → -8px)` 4s ease-in-out 循环 |
| 背景光晕         | `hero-glow` CSS class（径向渐变光圈 + glow-pulse 4s 脉冲动画） |

### 2.3 右列：文字内容

```
┌─────────────────────────────────┐
│                                 │
│   やればできる！                 │ ← Slogan, font-family (ja), text-2xl (24px)
│                                 │   color-text-secondary, letter-spacing 0.05em
│   KONG JUN SIENG               │ ← text-4xl (36px), color-text-primary, font-weight 700
│                                 │
│   Software Developer /          │ ← text-lg (18px), color-text-secondary
│   全栈探索者                     │
│                                 │
│   ┌──────────────────┐          │
│   │ 查看作品          │          │ ← OptionButton 组件
│   └──────────────────┘          │   背景图 /images/option-button.png
│                                 │   hover: scale(1.02) x(4)
│   Scroll ↓                     │ ← 小字引导提示, text-sm, color-text-secondary
│                                 │
└─────────────────────────────────┘
```

各元素间距（从上到下）：
- `mt-4`（Slogan → Name）
- `mt-2`（Name → Title）
- `mt-6`（Title → CTA 按钮）
- `mt-4`（CTA 按钮 → 滚动引导）

### 2.4 背景

| 属性     | 值                              |
| -------- | ------------------------------- |
| 背景色   | `bg-background`                  |
| 装饰元素 | `hero-glow`（`position: absolute`，`top: 0`，`right: -10%`，`width: 40vh`，`height: 40vh`） |
| 光晕动效  | `glow-pulse` 4s ease-in-out infinite，`opacity 0.4→0.8→0.4` |

### 2.5 Tablet 响应式（768px–1023px）

```
┌──────────────────────────────────────────────┐
│                                              │
│  ┌────────────┐  ┌────────────────────────┐  │
│  │            │  │ やればできる！           │  │
│  │  立绘      │  │ KONG JUN SIENG          │  │
│  │  缩小     │  │ Software Developer /    │  │
│  │  50%宽    │  │ 全栈探索者               │  │
│  │            │  │ [查看作品]              │  │
│  └────────────┘  └────────────────────────┘  │
│       ← 45% →       ← 55% →                 │
└──────────────────────────────────────────────┘
```

- Hero 高度：`min-h-screen`（桌面端，不超过屏幕）
- 立绘宽度缩至 45%，高度 `50vh`
- 文字适当缩小：Name `text-3xl`，Slogan `text-xl`
- 背景光晕适当减弱

### 2.6 Mobile 响应式（<768px）

```
┌─────────────────────────┐
│     [导航栏 汉堡菜单]     │
│                         │
│  ┌─────────────────┐    │
│  │                 │    │
│  │   立绘全屏      │    │ ← width 100%，fill
│  │   object-cover  │    │    object-position: "center 45%"
│  │   含渐变 overlay │    │    底部 bg-gradient-to-t from-background 遮罩
│  └─────────────────┘    │
│                         │
│  やればできる！          │
│                         │
│  KONG JUN SIENG         │
│                         │
│  Software Developer /   │
│  全栈探索者              │
│                         │
│  ┌──────────────┐       │
│  │  查看作品     │       │ ← 全宽按钮
│  └──────────────┘       │
│                         │
├─────────────────────────┤
│       ↓ 内容区块          │
└─────────────────────────┘
```

- **布局变列**：`flex-direction: column`，立绘在上文字在下（`min-h-[100dvh]`）
- 立绘：`absolute inset-0`，`w-full h-full`，`object-position: center 45%`
- 文字区：`absolute bottom-0` + `bg-gradient-to-t from-background from-30%` 渐变遮罩覆盖
- 文字：居中对齐，文本缩小一级
- 按钮：`w-full`
- 高度：`min-h-[100dvh]`（由内容决定，消除底部留白）
- 底部内边距：`pb-8`（32px，比桌面端减半）
- 背景光晕：移动端低 opacity（`0.3`），保留视觉感知但降低性能开销

## 七、Section 过渡台词

### 7.1 行为描述

每个 Section 切换处显示一条水平装饰线 + 居中表情符号（kaomoji），模拟游戏中"下一章"的过渡效果。

```
       ─────────────────────────────────
              ~ (∠・ω< )⌒★ ~
       ─────────────────────────────────
```

- 使用 `<SectionTransition text={t("transitions.xx")} />` 组件渲染
- 结构：贯穿的水平线 (`border-t border-border`) + 居中文本
- 文本包裹蓝色波浪符：`<span class="text-dialog-blue opacity-40">~</span> 文本 <span>~</span>`
- 动画：Framer Motion `transitionFade` 变体 (scale: 0.92→1, opacity: 0→1, 400ms)
- 触发时机：`whileInView`，`viewport: { once: true }`
- 文本来源：`messages/{lang}.json` 的 `transitions` 键（实际为颜文字 kaomoji）

### 7.2 参数

| 属性 | 值 |
|------|-----|
| 结构 | 水平贯穿线 + 居中 `~ text ~` |
| 动画 | Framer Motion `transitionFade`：`scale: 0.92→1, opacity: 0→1, 400ms` |
| 触发时机 | `whileInView`，`viewport: { once: true }` |
| 文本来源 | `messages/{lang}.json` 的 `transitions` 键 |
| 实现 | `<SectionTransition text={t("heroToCaseStudies")} />` |
