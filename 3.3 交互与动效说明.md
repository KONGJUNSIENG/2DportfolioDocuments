# 3.3 交互与动效说明

**项目：** KONG JUN SIENG — Software Developer Portfolio  
**品牌调性：** 日系萌系 × 浅色科技感，Gal 社风格柔和动效  
**动画引擎：** Framer Motion（JS 驱动）+ CSS Animations（装饰性/循环动画）  
**文档目标：** 定义每个交互的动效参数、时序、实现路径与禁用策略，供 AI Agent 直接生成动效代码。

## 一、动画系统架构

### 1.1 全局动画 Variants（集中管理）

所有 Framer Motion variants 集中定义在 `src/lib/animations.ts`，组件只引用 variant 名称，不重复写动画参数。

```typescript
// src/lib/animations.ts — 全局动画 variants
export const fadeInUp = {
  hidden: { opacity: 0, y: 20 },
  visible: {
    opacity: 1,
    y: 0,
    transition: { duration: 0.5, ease: [0.16, 1, 0.3, 1] },
  },
}

export const staggerContainer = {
  hidden: {},
  visible: {
    transition: {
      staggerChildren: 0.15,
      delayChildren: 0.1,
    },
  },
}

export const staggerItem = {
  hidden: { opacity: 0, y: 20 },
  visible: {
    opacity: 1,
    y: 0,
    transition: { duration: 0.5, ease: [0.16, 1, 0.3, 1] },
  },
}

export const pageTransition = {
  initial: { opacity: 0 },
  animate: { opacity: 1, transition: { duration: 0.2 } },
  exit: { opacity: 0, transition: { duration: 0.15 } },
}
```

使用方式（示例卡片组件）：
```tsx
<motion.div variants={staggerItem}>
  <Card />
</motion.div>
```

### 1.2 缓动函数映射

| Token           | 值                                   | 使用场景           |
| --------------- | ------------------------------------ | ------------------ |
| `ease-in-soft`  | `cubic-bezier(0.16, 1, 0.3, 1)`     | 入场动画           |
| `ease-out`       | `cubic-bezier(0.25, 0.1, 0.25, 1)`  | hover 反馈         |
| `linear`        | 无缓动                               | 视差驱动           |

### 1.3 时长映射

| Token      | 值     | 使用场景                          |
| ---------- | ------ | --------------------------------- |
| `fast`     | 200ms  | hover 状态切换、颜色过渡          |
| `normal`   | 300ms  | 按钮交互、卡片 hover              |
| `slow`     | 500ms  | Section 入场 fadeInUp             |
| `ambient`  | 800ms  | Hero 入场首帧、大元素渐入         |

## 三、Section 入场动画（whileInView + Stagger）

### 3.1 参数总表

| 区块         | Container Variant | Item Variant | staggerChildren | once  | 说明                         |
| ------------ | ----------------- | ------------ | --------------- | ----- | ---------------------------- |
| Case Studies | `staggerContainer` | `staggerItem` | 0.2             | true  | 仅 1 张卡片，效果为单次入场  |
| Projects     | `staggerContainer` | `staggerItem` | 0.15            | true  | 2 张卡片逐个入场             |
| About        | `staggerContainer` | `staggerItem` | 0.1             | true  | 文字 → 标签行                |
| Contact      | `staggerContainer` | `staggerItem` | 0.2             | true  | 左列表单 → 右列信息          |

### 3.2 通用实现模板

```tsx
// 所有 Section 组件复用此模式
"use client"
import { motion } from "framer-motion"
import { staggerContainer, staggerItem } from "@/lib/animations"

export function ProjectsSection() {
  return (
    <motion.section
      variants={staggerContainer}
      initial="hidden"
      whileInView="visible"
      viewport={{ once: true, amount: 0.2 }}
    >
      {/* Section 标题单独处理，不属于 stagger */}
      <h2 className="text-xl text-left">作品</h2>

      <div className="grid grid-cols-2 gap-6 mt-6">
        {projects.map((project) => (
          <motion.div key={project.slug} variants={staggerItem}>
            <ProjectCard project={project} />
          </motion.div>
        ))}
      </div>
    </motion.section>
  )
}
```

### 3.3 Section 标题入场

Section 标题`<h2>`的入场独立于卡片 stagger：

```tsx
<motion.h2
  className="text-xl"
  initial={{ opacity: 0, y: 15 }}
  whileInView={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.4, ease: [0.16, 1, 0.3, 1] }}
  viewport={{ once: true }}
>
  案例研究
</motion.h2>
```

标题与卡片的时间关系：
- 标题先入场（y: 15 → 0, 400ms）
- 完成后再触发卡片 stagger

## 四、页面过渡（C 方案 — 整页淡入淡出）

### 4.1 实现方案

```tsx
// app/[lang]/layout.tsx — 页面过渡核心
"use client"
import { motion, AnimatePresence } from "framer-motion"
import { usePathname } from "next/navigation"
import { pageTransition } from "@/lib/animations"

export default function LocaleLayout({
  children,
  params,
}: {
  children: React.ReactNode
  params: { lang: string }
}) {
  const pathname = usePathname()

  return (
    <div>
      <Navbar />
      <AnimatePresence mode="wait">
        <motion.main
          key={pathname}
          variants={pageTransition}
          initial="initial"
          animate="animate"
          exit="exit"
        >
          {children}
        </motion.main>
      </AnimatePresence>
      <Footer />
    </div>
  )
}
```

### 4.2 参数

| 属性     | 值                                    |
| -------- | ------------------------------------- |
| initial  | `opacity: 0`                          |
| animate  | `opacity: 1`，`transition.duration: 0.2` |
| exit     | `opacity: 0`，`transition.duration: 0.15` |
| mode     | `"wait"`（等待 exit 完成才进入 animate）    |
| key      | `pathname`（变化时触发过渡）               |

### 4.3 动画时序

```
用户点击 Case Study 卡片
  → 路由变化 → pathname 改变
  → exit: 当前页面 opacity: 1 → 0 (150ms)
  → 等待 exit 完成
  → initial: 新页面 opacity: 0
  → animate: 新页面 opacity: 0 → 1 (200ms)
```

### 4.4 防布局抖动

`<motion.main>` 在 exit 期间设置 `position: absolute`，防止 exit 元素消失瞬间布局塌缩：

```tsx
<motion.main
  key={pathname}
  layout
  className="relative"
  {...pageTransition}
  // 退出时 position: absolute 避免残留占位
  onExitComplete={() => {
    window.scrollTo({ top: 0 })
  }}
>
  {children}
</motion.main>
```

## 五、语言切换过渡（B 方案 — 内容区域淡入淡出）

### 5.1 实现方案

```tsx
// components/LocaleContent.tsx — 包裹内容区域
"use client"
import { motion, AnimatePresence } from "framer-motion"
import { useLocale } from "next-intl"

export function LocaleContent({ children }: { children: React.ReactNode }) {
  const locale = useLocale()

  return (
    <AnimatePresence mode="wait">
      <motion.div
        key={locale}
        initial={{ opacity: 0 }}
        animate={{ opacity: 1, transition: { duration: 0.5 } }}
        exit={{ opacity: 0, transition: { duration: 0.3 } }}
      >
        {children}
      </motion.div>
    </AnimatePresence>
  )
}
```

### 5.2 使用方式

```tsx
// app/[lang]/layout.tsx — 包装所有语言敏感内容
<LocaleContent>
  <Navbar />
  <main>{children}</main>
  <Footer />
</LocaleContent>
```

### 5.3 关键点

- `key={locale}` 在语言切换时触发 AnimatePresence 替换
- exit 时 opacity 0（300ms）→ 新内容 opacity 1（500ms）
- 导航栏、页脚等公共组件随内容一起过渡，避免视觉闪烁
- 语言切换时 Hero 不重新播放出场序列（仅文字内容替换）

## 六、视差效果（A 方案 — Hero 立绘 + 背景视差）

### 6.1 实现方案

```tsx
// components/HeroSection.tsx — 视差部分
"use client"
import { useScroll, useTransform, useSpring, motion } from "framer-motion"
import { useMediaQuery } from "@/hooks/useMediaQuery" // 自定义 hook

export function HeroParallax() {
  const isDesktop = useMediaQuery("(min-width: 1024px)")
  const { scrollYProgress } = useScroll()

  // 仅在 Desktop 启用视差
  const yOffset = useTransform(
    scrollYProgress,
    [0, 0.3],
    isDesktop ? [0, -60] : [0, 0]
  )
  const glowOpacity = useTransform(
    scrollYProgress,
    [0, 0.3],
    isDesktop ? [0.6, 0] : [0.3, 0.3]
  )

  // useSpring 增加阻尼感
  const smoothY = useSpring(yOffset, { stiffness: 100, damping: 30 })

  return (
    <section className="relative h-screen overflow-hidden">
      {/* 立绘层 - 0.8x 速度 */}
      <motion.div
        className="absolute left-0 bottom-0 w-[60%]"
        style={{ y: smoothY }}
      >
        <Image src="/images/hero-character.png" alt="" priority />
      </motion.div>

      {/* 光晕层 - 0.5x 速度 */}
      <motion.div
        className="hero-glow"
        style={{ opacity: glowOpacity }}
      />

      {/* 文字层 - 1x 速度，无视差 */}
      <div className="relative z-10 w-[40%] ml-auto">
        {/* ... 文字内容 */}
      </div>
    </section>
  )
}
```

### 6.2 参数映射

| 元素      | scrollYProgress 范围 | 变换        | 输出范围 | 速度倍率 |
| --------- | -------------------- | ----------- | -------- | -------- |
| Hero 立绘 | `[0, 0.3]`           | `y`         | `[0, -60]` | 0.8x    |
| 背景光晕  | `[0, 0.3]`           | `opacity`   | `[0.6, 0]` | 0.5x    |
| Hero 文字 | —                    | 无视差      | —        | 1x       |

### 6.3 响应式禁用

```typescript
// hooks/useMediaQuery.ts
export function useMediaQuery(query: string): boolean {
  const [matches, setMatches] = useState(false)
  useEffect(() => {
    const mql = window.matchMedia(query)
    setMatches(mql.matches)
    const handler = (e: MediaQueryListEvent) => setMatches(e.matches)
    mql.addEventListener("change", handler)
    return () => mql.removeEventListener("change", handler)
  }, [query])
  return matches
}
```

Desktop（≥1024px）启用视差，Tablet / Mobile 禁用。

### 6.4 性能注意

- 视差元素限制 2 个（立绘 + 光晕），不额外增加
- 使用 `useSpring` 防止突变导致的视觉抖动
- 视差元素添加 `will-change: transform`

## 八、导航栏滚动效果

### 8.1 实现方案

```tsx
// components/Navbar.tsx
"use client"
import { useScroll, useTransform, motion } from "framer-motion"

export function Navbar() {
  const { scrollY } = useScroll()
  const boxShadow = useTransform(
    scrollY,
    [0, 50],
    ["0 0 0 transparent", "var(--shadow-sm)"]
  )

  return (
    <motion.nav
      className="fixed top-0 z-50 h-16 w-full
                 bg-[rgba(255,250,253,0.85)]
                 backdrop-blur-md
                 flex items-center px-4 lg:px-8"
      style={{ boxShadow }}
    >
      {/* 导航内容 */}
    </motion.nav>
  )
}
```

### 8.2 行为描述

- `scrollY` = 0：背景完全透明，无阴影
- `scrollY` > 50px：`backdrop-blur` 生效 + `shadow-sm`
- 过渡平滑：Framer Motion useTransform 连续映射，非 JS scroll 事件监听

### 8.3 移动端

导航固定顶部行为不变。背景模糊 + 阴影规则与 Desktop 一致。

## 十、无障碍与性能

### 10.1 prefers-reduced-motion

```css
/* globals.css */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

用户开启系统"减少动效"后，所有动画直接跳过，显示最终态。

### 10.2 性能注意事项

- **避免布局抖动（Layout Thrashing）**：stagger 动画添加 `will-change: transform, opacity`
- **减少 JS 开销**：背景光晕 / 角色浮动使用 CSS animation，不叠加 Framer Motion 逐帧
- **视差元素上限**：最多 2 个（立绘 + 光晕），不再扩展
- **图片避免 Framer Motion 动画**：立绘使用 CSS 浮动动画，Framer Motion 只控制入场 opacity + y
- **AnimatePresence mode="wait"**：确保退出动画完成后才渲染新内容，避免同时渲染导致的性能峰值
- **viewport once: true**：Section 入场动画只触发一次，不重复
